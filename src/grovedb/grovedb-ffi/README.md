# GroveDB FFI

C-compatible Foreign Function Interface (FFI) bindings for GroveDB, a hierarchical authenticated data structure optimized for efficient secondary index queries and cryptographic proofs.

## Features

- **Full CRUD Operations** - Insert, get, and delete elements at any path
- **Transaction Support** - ACID-compliant transactions with commit/rollback
- **Query System** - Range queries with limits, offsets, and multiple query types
- **Cryptographic Proofs** - Generate and verify Merkle proofs for any query
- **All Element Types** - Item, Tree, SumTree, BigSumTree, CountTree, CountSumTree, Reference

## Build

```bash
# Build the FFI library
cargo build -p grovedb-ffi

# Build release version
cargo build -p grovedb-ffi --release

# Run tests
cargo test -p grovedb-ffi --all-features
```

The build produces:
- `libgrovedb_ffi.so` (Linux) / `libgrovedb_ffi.dylib` (macOS) - Dynamic library
- `libgrovedb_ffi.a` - Static library
- `include/grovedb.h` - C header file (auto-generated by cbindgen)

## Usage

### Basic Example (C)

```c
#include <grovedb.h>
#include <stdio.h>

int main() {
    GroveDbError error = {0};

    // Open database
    grovedb_t* db = grovedb_open("/tmp/mydb", &error);
    if (!db) {
        printf("Error: %s\n", error.message);
        grovedb_free_string(error.message);
        return 1;
    }

    // Create a tree at root
    GroveDbElement* tree = grovedb_element_new_tree((ByteBuffer){0});
    GroveDbPath root_path = {NULL, 0};
    ByteBuffer key = {(uint8_t*)"users", 5};

    grovedb_insert(db, &root_path, key, tree, NULL, NULL, &error);
    grovedb_free_element(tree);

    // Insert an item in the tree
    GroveDbElement* item = grovedb_element_new_item(
        (ByteBuffer){(uint8_t*)"Alice", 5},
        (ByteBuffer){0}
    );

    ByteBuffer path_segments[] = {{(uint8_t*)"users", 5}};
    GroveDbPath users_path = {path_segments, 1};
    ByteBuffer alice_key = {(uint8_t*)"alice", 5};

    grovedb_insert(db, &users_path, alice_key, item, NULL, NULL, &error);
    grovedb_free_element(item);

    // Get the item back
    GroveDbElement* result = grovedb_get(db, &users_path, alice_key, NULL, &error);
    if (result) {
        printf("Got item with %zu bytes\n", result->value.len);
        grovedb_free_element(result);
    }

    // Get root hash
    uint8_t hash[32];
    grovedb_root_hash(db, NULL, &hash, &error);

    // Close database
    grovedb_close(db);
    return 0;
}
```

## Memory Management

The FFI follows these ownership rules:

### Input Data (Borrowed)
- `ByteBuffer` - Caller owns the data, must remain valid during the call
- `GroveDbPath` - Caller owns segments array and data

### Output Data (Owned)
- `GroveDbElement*` - Caller must free with `grovedb_free_element()`
- `OwnedByteBuffer` - Caller must free with `grovedb_free_byte_buffer()`
- `QueryResults*` - Caller must free with `grovedb_free_query_results()`
- `char*` (error messages) - Caller must free with `grovedb_free_string()`

### Handles
- `grovedb_t*` - Free with `grovedb_close()`
- `grovedb_transaction_t*` - Consumed by commit, or free with `grovedb_free_transaction()`
- `grovedb_path_query_t*` - Consumed by query execution, or free with `grovedb_free_path_query()`

## Thread Safety

- **Database Handle** (`grovedb_t*`) - Can be shared across threads (uses internal synchronization)
- **Transaction Handle** (`grovedb_transaction_t*`) - Should be used by a single thread at a time
- **Other Handles** - Not thread-safe, use from a single thread

## Error Handling

All functions that can fail take a `GroveDbError*` output parameter:

```c
GroveDbError error = {0};
bool success = grovedb_insert(db, &path, key, element, NULL, NULL, &error);

if (!success) {
    printf("Error code: %d\n", error.code);
    if (error.message) {
        printf("Error message: %s\n", error.message);
        grovedb_free_string(error.message);
    }
}
```

Error codes are defined in `GroveDbErrorCode` enum.

## API Reference

### Database Operations
- `grovedb_open()` - Open or create a database
- `grovedb_close()` - Close database and free resources
- `grovedb_flush()` - Flush pending writes to disk
- `grovedb_root_hash()` - Get Merkle root hash

### CRUD Operations
- `grovedb_insert()` - Insert an element
- `grovedb_get()` - Retrieve an element
- `grovedb_delete()` - Delete an element

### Element Creation
- `grovedb_element_new_item()` - Create Item element
- `grovedb_element_new_tree()` - Create Tree element
- `grovedb_element_new_sum_item()` - Create SumItem element
- `grovedb_element_new_sum_tree()` - Create SumTree element
- `grovedb_element_new_big_sum_tree()` - Create BigSumTree element
- `grovedb_element_new_count_tree()` - Create CountTree element
- `grovedb_element_new_count_sum_tree()` - Create CountSumTree element
- `grovedb_element_new_reference()` - Create Reference element

### Query Operations
- `grovedb_path_query_new()` - Create query builder
- `grovedb_path_query_add_key()` - Add key lookup
- `grovedb_path_query_add_range*()` - Add range queries
- `grovedb_path_query_set_limit()` - Set result limit
- `grovedb_path_query_set_offset()` - Set result offset
- `grovedb_query()` - Execute query

### Transaction Operations
- `grovedb_start_transaction()` - Begin transaction
- `grovedb_commit_transaction()` - Commit changes
- `grovedb_rollback_transaction()` - Discard changes
- `grovedb_abort_transaction()` - Abort without cleanup

### Proof Operations
- `grovedb_prove_query()` - Generate proof for query
- `grovedb_verify_query()` - Verify proof
